Материалы для учеников: интерактивный тренажёр нотаций, кейс-квест «от заказчика до
реализации» и текстовые кейсы для самостоятельной работы.

## Ссылка для учеников

**https://andreypol1991.github.io/sa-praktikum/**

Страница открывается в браузере, ничего устанавливать не нужно. Прогресс в интерактивных
материалах сохраняется локально в браузере ученика.

### Интерактивный кейс-квест «Сервис фитнес-клуба»

Полный путь аналитика за одно занятие:

1. **Заказчик** — письмо владельца сети и расписание «как есть».
2. **Интервью** — ученик сам формулирует минимум 8 вопросов, затем разбирает 12 ответов
   заказчика и сам выводит требования (готовые формулировки не выдаются).
3. **Требования** — памятка «маркер в речи → конструкция аналитика» и задания на закрепление.
4. **Процесс** — путь клиента и 8 решений по BPMN.
5. **Данные** — 10 шагов проектирования ERD.
6. **Реализация** — итоги и домашнее задание: построить полные диаграммы.

На каждом этапе есть примеры-спойлеры (открываются по клику) и наводящие подсказки —
сначала ученик думает сам.

### Тренажёр нотаций

84 задания в 7 модулях: теория по ERD, BPMN, UML и DFD, выбор нотации по ситуации,
мини-кейсы с решениями аналитика и сквозной кейс «доставка еды». Проверка мгновенная,
с разбором каждого ответа.

## Формат сдачи кейсов

Папка `Фамилия_кейсN`: картинка диаграммы, **исходный код** диаграммы (`.dbml`, `.bpmn`,
`.puml`) и `answers.md` с ответами на вопросы кейса и списком допущений. Код обязателен —
проверяется корректность модели, а не оформление картинки.
