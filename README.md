# Кейс-квест «Спроектируем сервис фитнес-клуба»

Интерактивный HTML-тренажёр для учеников: полный путь системного аналитика от письма
заказчика до передачи проекта в разработку.

## Ссылка для учеников

**https://andreypol1991.github.io/sa-praktikum/**

Открывается в браузере, ничего устанавливать не нужно, работает и с телефона.
Прогресс сохраняется локально в браузере ученика, кнопка «⟲ Начать с нуля» — в шапке.

## Как устроен квест

1. **Заказчик** — письмо владельца сети и расписание «как есть». Примеры: как аналитик
   читает такой бриф.
2. **Интервью** — ученик сам формулирует минимум 8 вопросов (готовых нет), затем разбирает
   12 ответов заказчика и **сам выводит требования** из каждой реплики.
3. **Требования** — памятка «маркер в речи → конструкция аналитика» и задания на закрепление.
4. **Процесс** — путь клиента и 8 решений по BPMN.
5. **Данные** — 10 шагов проектирования ERD.
6. **Реализация** — итоги, оценка и домашнее задание: построить полные диаграммы.

На каждом этапе есть примеры-спойлеры (открываются по клику) и наводящие подсказки —
сначала ученик думает сам, подсказка это запасной парашют.
