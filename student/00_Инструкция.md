# Инструкция для участника практикума

## Цель занятия

Научиться превращать текстовое описание предметной области в корректную диаграмму:
ERD, BPMN, UML (use case / activity / sequence) и DFD.

## Как устроены кейсы

Каждый кейс имеет одинаковую структуру:

1. **Легенда** — описание бизнеса «как есть», написанное языком заказчика.
2. **Фрагменты интервью** — реплики заказчика. Именно в них спрятаны связи, кардинальности и
   исключения. Читать их нужно как требования, а не как «воду».
3. **Задание** — что именно построить.
4. **Вопросы на понимание** — короткие письменные ответы.
5. **Ловушки** — блок «на что смотрит проверяющий». Это подсказка, а не полный список.

## Правила

- Не додумывайте сущности и шаги, которых нет в легенде. Если чего-то не хватает —
  **зафиксируйте допущение** отдельным пунктом «Допущения» и стройте по нему.
  Явно записанное допущение ошибкой не считается, молчаливое — считается.
- Именование:
  - ERD: таблицы — в единственном числе, `snake_case` (`user`, `course_enrollment`);
    первичный ключ — `id`; внешний ключ — `<таблица>_id`.
  - BPMN: задачи — глагол в инфинитиве + объект («Проверить наличие товара»).
    События — свершившийся факт («Заявка поступила», «Пропуск выдан»).
  - UML use case: «Что актор хочет сделать в системе?» — глагол + объект
    («Забронировать занятие»).
- Каждая диаграмма должна иметь название и, если участников больше одного, — дорожки/пулы.
- Стартовое событие — ровно одно на пул, если в легенде не сказано иное. Завершающих может
  быть несколько, но у каждого должен быть смысл («Заявка отклонена», «Товар выдан»).

## Формат сдачи

Для каждого кейса — папка `Фамилия_кейсN` с файлами:

- `diagram.png` (или `.svg`) — изображение;
- `diagram.txt` / `.dbml` / `.puml` / `.bpmn` — **исходник** диаграммы;
- `answers.md` — ответы на вопросы кейса и блок «Допущения».

## Тайминг (ориентир)

| Блок | Время |
|---|---|
| ERD (кейсы 1–2, любой на выбор + второй по желанию) | 40 мин |
| BPMN (кейсы 3–4) | 45 мин |
| UML (кейсы 5–7) | 50 мин |
| DFD (кейс 8) | 25 мин |
| Комплексный кейс 9 (командой) | 60 мин + защита |
